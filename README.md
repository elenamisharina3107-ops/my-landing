# Шаблон сайта со встроенной панелью Sveltia

Переиспользуемая заготовка: статический сайт на [Eleventy](https://www.11ty.dev/)
с готовой панелью [Sveltia CMS](https://github.com/sveltia/sveltia-cms), своим
входом по email/паролю (клиент не видит GitHub) и деплоем на Beget.

Полный план и принятые решения — `docs/superpowers/plans/2026-09-02-admin-panel-v2-sveltia.md`
(и то же самое HTML-документом — читать удобнее). Простыми словами всё устройство
описано там же, в разделе «Для Лены → Простым языком».

## Из чего это состоит

```
src/            сайт: шаблоны, стили, контент (_data, content), панель (admin/)
panel/          Node-приложение → /admin/_panel/ на Beget (вход, история, экспорт, пользователи)
.github/        робот сборки и деплоя (GitHub Actions)
scripts/        чек-листы и инструкции (Beget, деплой, — новый сайт ниже)
docs/           план разработки, инструкция для локальной работы
tests/          тесты (panel/ — Vitest, юнит; e2e — по мере надобности)
```

## Быстрый старт (локально)

```
npm install                # зависимости сайта
npm run dev                # http://localhost:8080 — сайт с автообновлением
```

Подробнее про локальную разработку сайта и панели — `docs/DEV.md`.

Node-приложение `panel/` — отдельный пакет:

```
cd panel
npm install
cp store/config.example.json store/config.json   # заполнить своими значениями
cp store/users.example.json store/users.json     # или создать первого владельца через users.js
npm test                                          # 48 тестов, без реального GitHub
npm start                                         # локально на :3000
```

## Как сделать новый сайт клиенту

Чек-лист — `scripts/new-site.md`. Коротко: копируешь заготовку → переписываешь
`src/admin/config.yml` под блоки клиента → заводишь репозиторий и Beget по
инструкциям в `scripts/` → создаёшь первого владельца.

## Статус разработки

Этапы 0–4 плана (сайт из файлов, панель Sveltia, вход/сессии/пользователи,
робот деплоя, история/экспорт) реализованы и покрыты тестами. Этапы 3.2/3.3
(живой запуск на Beget) и 2.4 (клик по кнопкам Sveltia в браузере) ждут
реального хостинга — см. план, там же отмечено, что уже проверено на
реальном GitHub-репозитории без браузера.

Этапы 5 (тиражирование) и 6 (боевой пилот) — в работе после первого живого
запуска.
