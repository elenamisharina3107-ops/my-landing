# Локальная разработка

## Сайт

```
npm install
npm run dev      # сборка + сервер http://localhost:8080 с автообновлением
npm run build    # разовая сборка в _site/
```

Контент лежит файлами:

- `src/_data/*.json` — одиночные блоки (первый экран, настройки, SEO);
- `src/content/services/*.md` — карточки услуг (список);
- `src/uploads/*` — оригиналы картинок. В сборку попадают только сжатые
  версии (`_site/img/`), которые делает шорткод `{% image %}`.

## Панель Sveltia CMS

Открыть `http://localhost:8080/admin/`.

Локально панель работает **без GitHub и без прокси-сервера**: нужен
браузер Chrome или Edge (File System Access API). На экране входа выбрать
«Work with local repository» и указать корневую папку проекта. Правки
пишутся прямо в файлы `src/`; коммит/пуш — вручную обычным git-клиентом.

Версия Sveltia CMS зафиксирована в `src/admin/index.html`. Обновляем
вручную после проверки.

## Что где настраивается для нового сайта

`src/admin/config.yml` — единственный файл со «списком полей». Меняешь
разделы/поля здесь + примеры контента в `src/_data` и `src/content`.
